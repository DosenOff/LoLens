About
LoLens / Draft Intel

A live champion-select overlay and dashboard for League of Legends: your own match history, a rank-specific population win-rate baseline pulled from Riot's API, and pool recommendations that combine both against whoever's in the lobby.

The corner overlay follows champ select automatically. This window is the full dashboard — open it any time from the tray icon.

Data sources
Personal match historyRiot match-v5, your account
Population baselineRiot league-v4 + match-v5, sampled seed players
Champion names / iconsData Dragon (public CDN)
Live champ selectLeague Client (LCU) local API
